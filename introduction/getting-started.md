# Erste Schritte

In diesem Handbuch finden Sie alle Informationen für den Einstieg in RealBoard, darunter die Erstellung von Boards, die Verwaltung von Abschnitten und die effektive Nutzung von Karten.

So starten Sie RealBoard:

1. **Anmelden**: Greifen Sie mit Ihren Zugangsdaten über das RealLives-Dashboard auf RealBoard zu. Klicken Sie anschließend auf die Schaltfläche „RealBoard“.

<figure><img src="../.gitbook/assets/Untitled design(22).png" alt=""><figcaption></figcaption></figure>

2. **Boards einrichten:** Erstellen Sie Boards für Ihre Aufgaben.

<figure><img src="../.gitbook/assets/Screenshot 2024-09-05 164627.png" alt=""><figcaption></figcaption></figure>

3. **Abschnitte hinzufügen:** Organisieren Sie Boards mit relevanten Abschnitten.

<figure><img src="../.gitbook/assets/Screenshot 2024-09-05 165600.png" alt=""><figcaption></figcaption></figure>

4. **Karten erstellen:** Schüler können Karten hinzufügen, um ihre Arbeit zu teilen.
<figure><img src="../.gitbook/assets/Screenshot 2024-09-05 165637.png" alt=""><figcaption></figcaption></figure>

5. **Aufgaben verwalten**: Weisen Sie Aufgaben zu und überwachen Sie den Fortschritt.

Eine ausführliche Anleitung finden Sie in den entsprechenden Abschnitten dieses Handbuchs.
