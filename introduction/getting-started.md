# Erste Schritte

In diesem Handbuch finden Sie alle Informationen für den Einstieg in RealBoard, darunter das Erstellen von Boards, das Verwalten von Abschnitten und die effektive Nutzung von Karten.

So starten Sie RealBoard:

1. **Anmelden**: Greifen Sie mit Ihren Zugangsdaten über das RealLives Dashboard auf RealBoard zu. Klicken Sie anschließend auf die Schaltfläche „RealBoard“.

<figure><img src="../.gitbook/assets/Untitled design(22).png" alt=""><figcaption></figcaption></figure>

2. **Boards einrichten**: Erstellen Sie Boards für Ihre Aufgaben.

<figure><img src="../.gitbook/assets/Screenshot 2024-09-05 173700.png" alt=""><figcaption></figcaption></figure>

3. **Abschnitte hinzufügen**: Organisieren Sie Boards mit relevanten Abschnitten.

<figure><img src="../.gitbook/assets/Screenshot 2024-09-05 173719.png" alt=""><figcaption></figcaption></figure>

4. **Karten erstellen:** Studierende können Karten hinzufügen, um ihre Arbeit zu teilen.

<figure><img src="../.gitbook/assets/Screenshot 2024-09-05 173738.png" alt=""><figcaption></figcaption></figure>

5. **Aufgaben verwalten:** Aufgaben zuweisen und Fortschritt überwachen.

Eine ausführliche Anleitung finden Sie in den entsprechenden Abschnitten dieses Handbuchs.
