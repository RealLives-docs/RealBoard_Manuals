# Über das RealLives Dashboard

So greifen Sie über das RealLives-Dashboard auf RealBoard zu:

1. <mark style="background-color:blue;">**Einloggen:**</mark> Öffnen Sie RealLives und melden Sie sich bei Ihrem Konto an.
2. <mark style="background-color:blue;">**Dashboard:**</mark> Gehen Sie zu Ihrem **Dashboard.**
3. <mark style="background-color:blue;">**RealBoard Taste:**</mark> Suchen Sie auf dem Dashboard nach der Schaltfläche **RealBoard**.

<figure><img src="../.gitbook/assets/Untitled design(22).png" alt=""><figcaption></figcaption></figure>

4. <mark style="background-color:blue;">**Klicken Sie auf die Taste:**</mark> Klicken Sie auf **RealBoard** Taste, um RealBoard in einem neuen Tab oder Fenster zu öffnen.

<figure><img src="../.gitbook/assets/Screenshot 2024-09-05 171044.png" alt=""><figcaption></figcaption></figure>

Von hier aus können Sie Boards anzeigen, Karten hinzufügen und Ihre Beiträge verwalten.
